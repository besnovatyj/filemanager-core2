# Модель угроз и меры безопасности

Файловый менеджер — самая опасная часть админки: он пишет файлы на сервер, к которому имеет доступ
веб-сервер. Ниже — что именно мы считаем угрозой и где в коде стоит защита. Документ обязателен к
обновлению при добавлении любой операции.

## 1. Границы доверия

- Всё, что пришло от клиента (путь, имя, файл, стратегия конфликта, курсор), — **недоверенное**.
- `describe` — подсказка для UI, **не** механизм защиты. Все проверки повторяются на сервере при
  каждом вызове.
- Фронтенд не знает реальных путей ФС, имён бакетов, ключей; он видит только `/{mount}/...`.

## 2. Угрозы и меры

| Угроза | Где защищаемся | Как |
|---|---|---|
| Directory traversal (`../`, `..\\`, NUL, `%2e%2e`) | `fs/path/VirtualPath` (первый рубеж), Flysystem `PathNormalizer` (второй) | путь **отклоняется**, а не чинится; сегменты `.`/`..`, `\`, управляющие символы запрещены; неканонический вид — ошибка |
| Выход за корень через симлинк | `LocalAdapterFactory` | `LocalFilesystemAdapter::SKIP_LINKS` — ссылки не разыменовываются и не показываются |
| RCE через загрузку исполняемого файла | `policy/ExtensionBlocklistRule` | блок-лист по **всем** dot-сегментам (`shell.php.jpg`); применяется к upload, rename, move/copy (целевое имя), mkdir |
| Обход блок-листа переименованием | `Renamer`, `Transfer` | те же правила на целевое имя любой операции, меняющей имя |
| Хранимый XSS через отдачу `.html`/`.svg` с домена админки | `DownloadOperation`, `Previewer`, `Thumbnailer` | `download` — только `attachment` + `nosniff`; `preview` — inline только для растровых изображений, тип по magic bytes (SVG/HTML/PDF исключены), плюс CSP `default-src 'none'; sandbox`. Публичные URL — статик-домен/CDN, не домен админки. `thumbnail` — всегда перекодированное изображение (исходные байты и метаданные наружу не уходят) |
| «Декомпрессионная бомба» — маленький PNG/JPEG в сотни мегапикселей, исчерпание памяти PHP при построении миниатюры | `Thumbnailer` | размер файла ≤ `limits.previewMaxBytes`; размеры из заголовка (`getimagesizefromstring`) ≤ `thumbnails.maxPixels` до декодирования; список `size` закрыт (`thumbnails.sizes`), чтобы нельзя было засорить кэш; ключ кэша включает mtime и размер файла |
| Раскрытие внутренних путей/стека | `api/ApiException`, `ApiController` | наружу — нейтральное сообщение и код; детали — в лог Yii |
| DoS большими файлами | `policy/MaxFileSizeRule` + ini PHP | лимит = min(конфиг, `upload_max_filesize`, `post_max_size`); лимит на число элементов пакета (`limits.maxBatchItems`) |
| DoS глубокой рекурсией (копирование/удаление огромных деревьев) | `Transfer`, `Deleter` | лимит элементов на одну операцию (`maxTransferEntries`), таймаут исполнения → в Фазе 10 асинхронные задания |
| Zip-bomb | (Фаза 10, `extract`) | лимит entries, суммарного распакованного размера, глубины |
| Злоупотребление tus: чужие загрузки, переполнение диска, бесконечные незавершённые | `fs/tus/TusServer`, `FileTusStore`, `File/tus/purge` | загрузка привязана к пользователю (чужая = 404), `Upload-Length` ограничен политикой размера, кусок не больше `chunkSize`, данные сверх длины → 413, TTL + очистка по cron, id — 32 hex (имена файлов безопасны по построению), временный каталог вне `@static`; в хранилище байты попадают только через `Uploader` (политика, санитизация) |
| CSRF | хост (Yii CSRF) | все мутации — POST c `X-CSRF-Token`; `download` — GET без побочных эффектов |
| Отсутствие/поломка авторизации | ядро `DefaultDenyAccessControl` (fail-closed) | каждая операция — отдельный маршрут; `describe` отдаёт только разрешённые |
| Перезапись «случайно» | `ConflictPolicy` | по умолчанию `fail`; перезапись только явным `onConflict: overwrite` |
| Перенос папки внутрь себя (потеря данных/зацикливание) | `Transfer` | `VirtualPath::isAncestorOf()` → `invalid_operation` |
| Удаление корня/mount'а | `Deleter` | `invalid_operation` |
| Некорректные имена (кроссплатформенные проблемы, Windows-резервы, trailing dots) | `naming/NameValidator` | правила отдаются клиенту, применяются на сервере |
| Unicode-омоглифы/невидимые символы в именах | `NameValidator` | запрет управляющих и форматирующих символов (Cc, Cf), NFC-нормализация (если есть intl) |
| Sniffing MIME браузером у загруженного контента | `ContentSniffRule` (опционально), `nosniff` при отдаче | правило выключено по умолчанию (ADR-10), включается конфигом |
| Утечка списка mount'ов пользователю без прав | `DescribeOperation` | mount'ы фильтруются по правам на `list` |
| Выход из папки сущности при работе из редактора | `api/scope/ScopeToken`, `fs/path/PathScope`, `Payload::path()` | виджет выпускает HMAC-токен области (пользователь + срок), сервер отклоняет любой путь запроса вне области; клиент лишь дублирует ограничение в UI |

## 3. Что делает клиент (в дополнение, не вместо)

- Валидация имени «на лету» по `describe.naming` — чтобы не отправлять заведомо плохое.
- Проверка размера файла до загрузки по `describe.upload.maxFileSize`.
- Экранирование всего, что вставляется в DOM: имена узлов рендерятся через `textContent`,
  никогда через `innerHTML` с данными.
- Публичные `url` вставляются в редактор только после проверки схемы (`http(s):` / относительный).

## 4. Что осознанно НЕ делаем

- Антивирус/ClamAV — вне зоны ответственности пакета; точка расширения — `PolicyRuleInterface`.
- Rate limiting — на уровне инфраструктуры (отложено осознанно, см. память проекта).
- Шифрование на стороне клиента — не требуется в модели угроз админки.
