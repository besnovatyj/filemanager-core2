# Взаимодействие: мышь, клавиатура, touch

Справочник по тому, как проводник реагирует на действия пользователя, и где это реализовано.
Модель повторяет проводник Windows на десктопе и мобильные файловые менеджеры на touch-экранах.

## 1. Два режима указателя

`ViewportStore` (`src/model/ViewportStore.ts`) даёт два сигнала:

- `narrow` — проводник уже 640px (по ширине **самого проводника**, а не окна: встроенный в узкую
  колонку менеджер ведёт себя как на телефоне);
- `coarse` — грубый указатель (`matchMedia('(pointer: coarse)')`): палец вместо мыши.

`narrow` меняет раскладку, `coarse` — размеры целей и модель тапов. Оба независимы: планшет с
клавиатурой в альбомной ориентации — `coarse`, но не `narrow`.

## 2. Панель содержимого (`fm-content-pane`)

### Мышь

| Действие | Результат |
|---|---|
| Клик | выделить только этот элемент |
| Ctrl+клик | переключить элемент, якорь → элемент |
| Shift+клик | диапазон от якоря |
| Ctrl+Shift+клик | добавить диапазон к выделению |
| Нажатие на выделенном элементе группы | группа сохраняется (чтобы её можно было тащить); отпускание без перетаскивания оставляет только этот элемент |
| Протяжка по пустому месту | рамка выделения; Ctrl — добавить к текущему; автопрокрутка у краёв |
| Двойной клик | папка — открыть; файл — в picker выбрать, в manager скачать |
| Правая кнопка | контекстное меню элемента (невыделенный элемент сначала выделяется) или папки |
| Перетаскивание элементов на папку/в дерево | переместить; с Ctrl/Alt — копировать |
| Перетаскивание файлов из ОС | загрузить в папку под курсором или в текущую (подсветка «Перетащите файлы сюда») |

### Клавиатура (фокус в списке)

| Клавиши | Действие |
|---|---|
| Стрелки, Home, End, PageUp, PageDown | фокус и выделение; Shift — диапазон; Ctrl — только фокус |
| Пробел / Ctrl+Пробел | выделить фокусный / переключить фокусный |
| Буквы | type-ahead: переход к первому имени с таким началом (буфер 0,8 с) |
| Enter | открыть (`open`) |
| Backspace, Alt+↑ | вверх (`up`) |
| Alt+←, Alt+→ | назад / вперёд |
| F5, Ctrl+R | обновить |
| F2 | переименовать inline |
| Delete | удалить |
| Ctrl+C, Ctrl+X, Ctrl+V | копировать / вырезать / вставить |
| Ctrl+A | выделить всё |
| Ctrl+U | загрузить |
| Ctrl+Shift+N | новая папка |
| Alt+Enter | свойства |
| Ctrl+Shift+V | переключить режим вида |
| Escape | снять выделение; при пустом выделении — закрыть окно |

Сочетания объявлены у команд (`shortcuts`), диспетчер — `commands/Keymap.ts`. В полях ввода
(адресная строка, inline-переименование, диалоги) сочетания списка не действуют.

### Touch (`coarse`)

| Жест | Результат |
|---|---|
| Тап по папке | открыть |
| Тап по файлу | выделить (в picker — это «кандидат»; подтверждение — кнопка «Выбрать») |
| Тап, когда что-то уже выделено | переключить выделение элемента (режим выделения: у элементов видны чекбоксы) |
| Тап по пустому месту | снять выделение (выход из режима выделения) |
| Долгое нажатие (0,5 с) | контекстное меню |
| Протяжка | прокрутка (рамка выделения на touch отключена) |
| Перетаскивание элементов | не используется (HTML5 DnD не работает на Android): перенос — вырезать/вставить |

Реализация: `onPointerDown` на touch ничего не выделяет, модель тапов живёт в `onClick`,
`lastPointerType` отличает тап от клика мыши. Размеры целей: строки 40px, кнопки 36px, иконки 20px
(`@media (pointer: coarse)` в `ui/theme/tokens.ts`).

## 3. Панель навигации (`fm-nav-pane`)

- Клик по строке — перейти; клик по шеврону — раскрыть/свернуть без перехода; двойной клик — раскрыть.
- Стрелки ↑/↓ — фокус; → раскрыть или вниз; ← свернуть или к родителю; Enter/пробел — перейти;
  Home/End.
- Правая кнопка / долгое нажатие — перейти в папку и открыть меню папки.
- Приём drop: узлы (переместить, Ctrl — копировать) и файлы ОС (загрузить) на папку под курсором.
- В узкой раскладке дерево — выдвижная панель («шторка») по гамбургеру в тулбаре, закрывается
  тапом по подложке или переходом в папку. Область видимости (scope) ограничивает корень дерева.

## 4. Адресная строка (`fm-address-bar`)

- Крошки: клик по сегменту — переход. В узкой раскладке показываются «…» и два последних сегмента;
  «…» открывает редактирование пути.
- Клик по пустому месту строки — редактирование пути: Enter — перейти (путь нормализуется:
  лишние слеши, `\`, пробелы), Escape — отмена, потеря фокуса — отмена.
- Поле справа — фильтр и поиск в одном: набор текста сужает текущую папку по подстроке имени на
  лету (сбрасывается при переходе); **Enter** — поиск по вложенным папкам на сервере (§9.15,
  если хранилище умеет), крошки сменяются заголовком «Результаты поиска: «запрос»» с папкой
  поиска и крестиком. Ctrl+F ставит фокус в поле. Escape в поле, крестик, опустошение поля или
  переход в другую папку закрывают поиск; F5 повторяет его. В результатах рядом с именем —
  расположение относительно папки поиска; двойной клик по найденной папке переходит в неё,
  по файлу — как обычно (открыть/выбрать). Строка состояния: «Найдено: N (показаны первые N)»,
  если сервер усёк список.

## 5. Тулбар (`fm-toolbar`)

Кнопки — команды реестра; состояние `disabled`/`aria-pressed` реактивно из `canExecute`/`isChecked`.
В узкой раскладке второстепенные кнопки (вперёд, обновить, вырезать, копировать, переименовать,
удалить, скачать, свойства) уходят в меню «Ещё», подписи прячутся, слева появляется гамбургер дерева.
Меню «Вид» — режимы, сортировка, панели.

## 6. Область предпросмотра (`fm-preview-pane`)

Включается кнопкой в тулбаре/меню «Вид» (`toggle-preview`), ширина тянется разделителем и
сохраняется. Показывает один выбранный элемент (при пустом выделении — текущую папку): изображение,
начало текстового файла (64 КБ) или иконку типа, плюс метаданные и кнопку «Скачать». Запрос уходит
через 200 мс после смены выделения, предыдущий отменяется; при скрытой панели запросов нет.
В узкой раскладке панель накрывает содержимое справа и закрывается крестиком.

## 7. Окно (`fm-window`)

Перетаскивание за заголовок, изменение размера за края и углы (размер сохраняется в `ViewStore`),
закрытие крестиком, Escape, кликом по фону. На экранах уже 640px окно занимает весь экран
(`100dvh`), ручки ресайза скрыты.

## 7. Индикация ожидания

Ни один процесс не должен быть невидимым. Уровни: плейсхолдер «Подключение к серверу…» в окне или
контейнере до ответа `describe`; спиннер в панели содержимого при первой загрузке папки;
индикатор «Ожидание ответа сервера…» в строке состояния при любом запросе дольше 250 мс
(`ActivityStore` считает запросы через `TrackingFsClient`); панель операций для мутаций и
загрузок с прогрессом; диалог свойств открывается сразу и дозаполняется по ответу `stat`.

## 8. Диалоги и меню

`fm-dialog`: фокус-ловушка (Tab циклится внутри), Enter — кнопка по умолчанию, Escape/фон/крестик —
отмена; в prompt-диалоге валидация «на лету» с подсказкой. `fm-menu`: клик вне, Escape, потеря
фокуса окна, ресайз — закрытие; стрелки/Home/End/Enter/Пробел — навигация; позиционирование
внутри окна браузера.

Оба живут на `document.body` (а не внутри окна), чтобы не зависеть от stacking-контекстов хоста;
тема (`data-theme`) копируется с корня проводника.
